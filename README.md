Repositório dos meus estudos de automação em Python. Tô aprendendo na prática e subindo os códigos aqui conforme vou evoluindo.

## Como comecei

Comecei aprendendo com o professor Jonathan de Souza, do canal Dev Aprender. O vídeo que usei de base foi esse:

https://www.youtube.com/watch?v=rCRyCM4JC3E

## O que tem aqui

Por enquanto, tô usando a biblioteca `openpyxl` pra criar e manipular planilhas do Excel. Algumas das coisas que tô aprendendo a fazer são:

- Criar planilhas com dados
- Ler planilhas existentes
- Formatar células, colocar negrito, cores de fundo e ajustar a largura das colunas
- Criar gráficos de barras, pizza e linha
- Organizar dados em várias abas

## Bibliotecas usadas

- `openpyxl`

Pra instalar, é só rodar:

```bash
pip install openpyxl
```

## Como rodar

É só executar o arquivo que você quer testar:

```bash
python nome_do_arquivo.py
```

O script vai gerar um arquivo `.xlsx` na mesma pasta. Se der erro de `PermissionError`, provavelmente o arquivo tá aberto no Excel. É só fechar e rodar de novo.
